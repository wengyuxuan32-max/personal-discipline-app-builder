# Personal Discipline App Builder

一个用于设计和制作个性化 Android 自律软件的 Codex Skill。

它不会把所有人套进同一个固定模板，而是先了解用户的手机、使用目的和偏好，再让用户从完整功能池中自由选择，最终形成可以继续开发和迭代的 Android App 规格。

## 这个 Skill 有什么用

适合下面这些需求：

- 想做一款只给自己或朋友使用的 Android 自律 App。
- 想把习惯、任务、提醒、专注、复盘、记账、成长或愿望集中到一个软件中。
- 不知道该选哪些功能，希望先获得推荐，再自行增删。
- 希望先把需求讨论清楚，再制作 APK。
- 希望软件可以备份、换手机、覆盖更新并继续迭代，而不是一次性原型。

它不适合普通的自律建议，也不用于已有 App 的单个 Bug 修复。

## 使用流程

### 1. 了解设备和目的

Skill 首先询问：

- 手机品牌、型号和 Android 版本。
- 希望软件主要帮助什么，例如督促执行、记录变化、检查计划、建立习惯、减少拖延、管理目标、提升专注或管理预算。

使用目的可以多选，并标出最重要的一项。

### 2. 选择定制方式

用户自己选择：

- **快速定制**：集中选择功能，系统补全普通细节，只确认关键冲突和高影响决定。
- **精细定制**：按模块逐步选择，对选中的功能一次讨论一个关键问题。

Skill 不会擅自默认其中一种模式。

### 3. 自由选择功能

完整功能池分为八个模块：

1. 自律执行
2. 计划与目标
3. 复盘与状态
4. 记账与预算
5. 成长与愿望
6. 数据洞察与建议
7. 便捷操作与个性化
8. 数据、隐私与同步

系统会突出推荐功能，但推荐不等于限制。用户可以选择任意数量的功能，也可以拒绝全部推荐后自行选择。

### 4. 生成完整规格

Skill 会整理：

- 页面与导航关系。
- 每个功能的新增、查看、编辑、完成、恢复、归档和删除规则。
- 时间、重复、提醒和权限行为。
- 统计、评分、报告和建议口径。
- 备份、换机、隐私、费用和更新方式。
- 当前版本不做和以后再做的内容。

只有用户确认规格并明确要求开始制作后，才进入 Android 实现阶段。

## 功能示例

功能库包含但不限于：

- 习惯与重复任务、今日结算、完成质量。
- 番茄钟、正倒计时、专注时长和时间记录。
- 普通通知、轻提醒、强闹钟和桌面小组件。
- 明日计划、未来日程、长期目标、里程碑和子任务。
- 每日、每周、每月复盘，以及心情、精力和睡眠记录。
- 支出、收入、预算、储蓄目标、账单日历和年度统计。
- 成长池、愿望清单、阅读清单和灵感箱。
- 完成率、专注趋势、综合评分和计划调整建议。
- 本地备份、跨手机导入、应用锁、云同步和协作。

涉及账号、云同步、联网 AI、在线协作或服务器的功能，会提前说明可能的费用、隐私和维护影响。

## 安装

将整个 `personal-discipline-app-builder` 文件夹放入 Codex 的 Skills 目录：

```text
~/.codex/skills/personal-discipline-app-builder/
```

目录中必须保留 `SKILL.md`、`agents/` 和 `references/`。

## 使用

在 Codex 中直接描述需求，或者显式调用：

```text
使用 $personal-discipline-app-builder 帮我设计一款属于自己的 Android 自律软件。
```

Skill 会从设备和主要目的开始，不需要用户提前整理完整需求。

## 隐私原则

- 每位用户的手机型号、任务、账单、愿望、复盘和其他个人内容只用于其当前项目。
- 不把一位用户的真实信息写回公共 Skill、示例或其他用户的方案。
- 公共功能库只保存通用能力，不保存任何用户的私人答案。
- 智能建议不得擅自增加、删除、移动或完成用户任务。

## 设计原则

- 推荐只提供参考，用户拥有最终决定权。
- 功能数量不设上限，但会说明复杂度和成本。
- 已经回答过的问题不重复询问。
- 用户授权系统决定时，采用合理默认值并允许以后修改。
- 规格确认前不擅自开始制作。
- Android 实现必须考虑输入可用性、数据迁移、备份兼容和覆盖更新。
